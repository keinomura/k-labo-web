# ディーラー・パートナープログラム説明書

## パートナープログラム概要

### K-Labo ディーラーパートナーとは

医療機器販売・ITソリューション提供企業様向けの **再販パートナープログラム** です。
貴社の既存顧客ネットワークを活かし、AI診療録作成サービスを販売・サポートすることで、
**月額ストック型の継続収益** を獲得できます。

### なぜパートナーになるべきか

| メリット | 詳細 |
|---------|------|
| **継続的なストック収入** | 顧客が契約している限り、毎月コミッションが発生 |
| **高いコミッション率** | 月額料金の **30%** が継続的に支払われます |
| **低い導入ハードル** | ブラウザだけで利用開始。機器設置・工事不要 |
| **高い継続率** | 業務効率化ツールは一度使うとやめられない |
| **既存商材との親和性** | 電子カルテ・医療機器との組み合わせ提案が可能 |
| **専用管理ポータル** | 顧客管理・売上確認がリアルタイムで可能 |


### コミッションの特徴

- **毎月自動計算** - 管理ポータルでリアルタイム確認
- **継続型収入** - 顧客の契約が続く限り毎月支払い
- **組織単位課金** - 1契約でスタッフ全員が利用（追加課金なし）
- **解約リスク低** - 業務ツールは高い継続率

## ターゲット顧客と提案方法

### 主要ターゲット

#### Tier 1: クリニック（Clinic Support ¥25,800/月）

**規模**: 医師1-3名 + スタッフ5-15名

**提案のポイント**:
- 「診療録作成に毎日1-2時間かかっていませんか？」
- 「スタッフ全員で月額¥25,800。1人あたり¥1,720/月」
- 「14日間無料トライアルで効果を実感してください」

**効果的な診療科**:
- 内科（外来数が多い）
- 整形外科（診察＋処置の記録）
- 小児科（保護者説明の記録）
- 耳鼻咽喉科（短い診察の大量処理）
- 皮膚科（所見記録の効率化）

**刺さるメッセージ**:
> 「1日30人の外来で、診療録作成に1件5分 × 30人 = 2.5時間。
> AI診療録なら1件30秒 × 30人 = 15分。
> **毎日2時間以上の時短**で、年間500時間以上の削減です。」

#### Tier 2: 病院（Hospital Support ¥89,800/月）

**規模**: 医師5名以上 + スタッフ20-30名

**提案のポイント**:
- 「複数診療科で統一的に導入できます」
- 「スタッフ30名で月額¥89,800。1人あたり¥2,993/月」
- 「導入研修不要。ブラウザを開くだけで即利用開始」

**効果的な提案先**:
- 中規模総合病院
- 複数診療科を持つ病院
- 訪問診療を行う病院（モバイル対応）
- 教育研修を重視する病院（説明モード活用）

#### Tier 3: 専門クリニック（特定ニーズ）

**精神科・心療内科**:
> 「45分のカウンセリング内容を正確に記録。
> 説明モードで録音 → AI が自動で診療録を作成。
> 記録作成の負担なく、患者さんとの対話に集中できます。」

**栄養指導クリニック**:
> 「栄養指導の内容を自動記録。
> 指導終了と同時に記録が完成。
> 患者さんへの説明資料としてもQRコードで共有可能。」

## 導入フロー（ディーラー経由）

### Step 1: 顧客へのデモ・提案

1. 本ドキュメントと製品デモを使って提案
2. 14日間無料トライアルを案内
3. **トライアル登録は顧客自身でも、ディーラー代行でも可能**

### Step 2: トライアル開始

1. ディーラー管理ポータルから顧客組織を登録
2. プランを「Clinic Support」または「Hospital Support」に設定
3. 顧客にアカウント情報を連絡
4. **トライアル中の問い合わせ対応はディーラー様が一次窓口**

### Step 3: 有料プランへの移行

1. トライアル終了前に顧客に確認
2. ディーラー管理ポータルから有料移行を実行
3. Stripe決済が自動開始
4. コミッションの自動計算開始

### Step 4: 継続サポート

1. 月次の利用状況レポートを顧客に共有
2. プロンプトのカスタマイズ支援
3. 新機能のリリース案内
4. **K-Labo本部への技術エスカレーション対応**

## 想定Q&A（ディーラー向け）

**Q: 自社の顧客にだけ見えるように制御できますか？**
A: はい。ディーラーAdmin機能により、自社が登録した顧客のみが管理ポータルに表示されます。他ディーラーの顧客情報は一切見えません。

**Q: 顧客がディーラーを介さず直接契約することはありますか？**
A: 直販プラン（Clinic Premium ¥19,800）とディーラープラン（Clinic Support ¥25,800）は別プランです。ディーラー経由の顧客にはディーラープランが適用され、コミッションが発生します。

**Q: コミッション率は変動しますか？**
A: 標準30%ですが、販売実績に応じてボリュームインセンティブの設定が可能です。詳細は個別にご相談ください。

**Q: 顧客が解約した場合のコミッションはどうなりますか？**
A: 解約月をもってコミッションの支払いは終了します。日割り計算は行いません。

**Q: 既存の電子カルテとの連携について聞かれた場合は？**
A: QRコード方式のため、QRコードリーダー対応の電子カルテであればメーカーを問わず連携可能です。特定メーカーとの専用連携は現時点では対応していませんが、QRコード方式により幅広い互換性を確保しています。

**Q: 導入研修は必要ですか？**
A: 基本的には不要です。ブラウザを開いて録音ボタンを押すだけの簡単操作です。必要に応じて、オンラインでの簡易説明（30分程度）を提供可能です。

**Q: 医療情報のセキュリティは大丈夫ですか？**
A: 全通信はHTTPS暗号化、Clerk認証基盤による企業グレードセキュリティ、患者個人情報のログ除外（PHI保護）を実装しています。また、全操作ログを記録しており、監査対応も可能です。

## 製品コンセプト

### 何を解決するのか

医師・看護師が毎日の診療後に費やす **診療録作成時間を劇的に削減** します。

| 課題 | 従来 | 本サービス |
|------|------|-----------|
| 診療録作成 | 診療後にPCで手入力（1件5-15分） | 診療中に話すだけ（自動生成30秒） |
| 電子カルテ入力 | 手動コピー＆ペースト | QRコードスキャンで自動連携 |
| 記録漏れ | 記憶頼りで後から補完 | リアルタイム録音で正確に記録 |
| 複数職種対応 | 汎用テンプレートのみ | 医師・看護師・栄養士・受付ごとに最適化 |

### 誰が使うのか

**主要ターゲット**:
1. **開業医・クリニック** - 医師1名〜スタッフ15名規模
2. **中規模病院** - 複数診療科・30名以上のスタッフ
3. **個人開業の専門医** - 精神科・栄養指導など長時間診療

**利用シーン**:
- 外来診療中の記録（内科・整形外科・小児科など）
- 患者説明の記録（45分モード）
- 看護記録の作成
- 栄養指導の記録
- 受付業務の記録

## コア機能 - 顧客が求める価値

### 1. 話すだけで診療録が完成

**ワンタッチ録音 → AI文字起こし → 診療録自動生成**

- 録音ボタンを押して話すだけ
- AIが音声をリアルタイムに文字起こし
- GPT-5が医療用語を理解し、構造化された診療録を自動生成
- **処理時間: わずか30秒**

**技術的な強み**:
- OpenAI Whisper API による高精度音声認識
- 無音区間の自動検出（不要なAPI呼び出しを30%削減）
- 10秒タイムアウト最適化（従来比92%高速化）
- ネイティブ音声認識との自動切替（ブラウザ内蔵 + Whisper APIフォールバック）

### 2. QRコードで電子カルテに即連携

**診療録 → QRコード自動生成 → 電子カルテにスキャン**

- 生成した診療録を即座にQRコード化
- 長文は自動分割（複数QRコードに対応）
- 電子カルテシステムのバーコードリーダーでスキャンするだけ
- **手入力ゼロ、転記ミスゼロ**

**対応環境**:
- タブレット（iPad等）: QR内容プレビュー表示
- スマートフォン: スナップスクロールで1つずつ表示
- PC: フル表示 + 物理キーボードショートカット対応

### 3. 職種ごとに最適化されたAIプロンプト

**医師・看護師・栄養士・受付 — それぞれに最適なテンプレート**

- 職種選択だけでAIの出力形式が自動最適化
- クリニック独自のテンプレートも作成可能（Clinic以上プラン）
- プロンプトのバージョン管理で変更履歴を完全追跡
- ワンクリックでロールバック可能

### 4. 45分の患者説明モード

**長時間の患者説明を正確に記録**

- 最大45分の連続録音（通常モードの3倍）
- 患者説明専用のAIプロンプト（症状説明・検査説明・治療説明）
- オレンジ色のUIで通常モードと視覚的に区別
- 説明内容をそのまま診療録として保存

### 5. 衛生に配慮した物理キーボード操作

**医療現場のために設計されたハンズフリー操作**

- `Ctrl+1`: 録音の開始/停止（画面に触れずに操作）
- `Ctrl+2`: QRコード表示の切替（ホールドモード対応）
- iPad + 外付けキーボードでの利用に最適化
- 診療中に画面操作が不要

### 6. チーム管理とクリニック独自ブランディング

**スタッフ全員で使える、あなたのクリニック専用ツール**

- メンバー招待（メールベース）
- 5段階の権限管理（オーナー・管理者・メンバー・経理・閲覧者）
- クリニック名・ロゴ・テーマカラーのカスタマイズ
- 組織全体の利用状況ダッシュボード

## 利用フロー（30秒で完了）

```
① 録音開始（ボタンorCtrl+1）
    ↓ リアルタイム文字起こし表示
② 録音停止（ボタンorCtrl+1）
    ↓ AI自動生成（約10-15秒）
③ 診療録完成 → QRコード自動生成
    ↓
④ 電子カルテでQRスキャン → 入力完了
```

**Express Mode**: ①〜④が全自動。録音停止後、最適なプロンプトを自動選択して診療録を生成。
